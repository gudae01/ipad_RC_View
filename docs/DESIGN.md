# 디자인과 인터랙션

모든 풍경은 합성 예시입니다. 장치 이름·해상도·FPS에 실측하지 않은 값을 넣지 않았습니다. 네이티브 뷰는 고정된 작업 크기가 아니라 창의 가용 공간을 사용합니다.

## 토큰과 컴포넌트

`design/tokens.json`과 `RCView/UI/DesignSystem.swift`를 참고합니다.

- 배경 `#F8F9FA`, 표면 `#FFFFFF`, 본문 `#1A1A1A`, 보조 `#667085`.
- 테두리 `#E5E7EB`, 단일 강조색 `#526D82`, 영상 여백 검정.
- 제목 24–28pt/Semibold, 본문 15–17pt, 보조 12–13pt. 시스템 동적 글꼴 지원.
- 기본 간격 8pt, 페이지 여백 24pt(좁은 창은 16pt), 카드 내부 16–20pt.
- 카드 반경 12pt, 버튼 반경 10pt, 최소 터치 영역 44pt.
- 공통 컴포넌트: 강조/보조 버튼, 테두리 카드, 아이콘+텍스트 상태 칩, 탭 바, 빈 상태 안내.
- SF Symbols 아웃라인 사용. 색상만으로 연결 상태를 표현하지 않음.

## 화면별 조작

**뷰어:** 주요 영역을 영상에 할당합니다. 장치·형식·관측 FPS는 작은 메타데이터 줄로 표시합니다. 확대 초기화/회전/전체 화면만 주요 조작으로 둡니다. 핀치는 화면 표시만 확대합니다. 프로필은 로컬 설정, 알림은 연결 이력 시트입니다.

**전체 화면:** 검정 배경으로 헤더/탭을 숨깁니다. 한 번 터치하면 조작부가 표시되며 약 3초 뒤 숨겨집니다. 버튼 조작/핀치 중에는 타이머를 갱신합니다. 연결 해제나 프레임 중단 시 영상을 가리고 상태를 표시하여 마지막 프레임을 현재 영상으로 오해하지 않게 합니다. 표시 회전은 장치 자세와 독립된 90도 단위 변환입니다.

**연결 대기:** 큰 안내와 다시 찾기/연결 방법 버튼. 실기기에 입력이 없으면 샘플을 재생하지 않습니다.

**연결:** 실제 시스템 이름의 장치 목록, 활성 형식, 지원 형식, 권한, 프레임 상태. 지원 형식은 장치가 보고한 형식과 프레임률 범위 안에서 제시합니다. HDMI 원본 기기 정보는 추측하지 않습니다.

**설정:** 자동 미리보기/전체 화면, 화면 꺼짐 방지, 맞춤 방식, 표시 회전, 도움말, 버전. 화면 채우기는 가장자리 잘림을 안내합니다.

## 재생성

Pillow와 한국어 글꼴이 설치된 Windows에서 다음을 실행합니다.

```powershell
py -3 design/render_mockups.py
```

다른 OS에서는 `RCVIEW_KOREAN_FONT`와 `RCVIEW_KOREAN_BOLD_FONT` 환경변수로 글꼴 경로를 지정합니다. 렌더러는 앱 빌드 의존성이 아닙니다.
